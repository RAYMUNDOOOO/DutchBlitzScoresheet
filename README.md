# Dutch Blitz Scoresheet
A simple web application built with Svelte to keep track of player scores in a game
of [Dutch Blitz](https://dutchblitz.com/).

## Current functionality
So far this is just the MVP, so it can:

- Add new players to the game with a pre-defined name (John)
- Update the score of players in between rounds
- Start and stop a round
- If a round has started, scores cannot be updated

## How to run it
```bash
bun run dev --open # Will open in your default browser
```
